# 📌 Unsaon pag contribute?

Follow these steps to contribute safely and correctly.

## 1️⃣ Fork the Repository

Click the **Fork** button at the top right of this repository.

This creates your own copy of the project.

---

## 2️⃣ Clone Your Fork

```bash
git clone https://github.com/jyn626/IT121_POS.git
cd REPOSITORY-NAME
```

---

## 3️⃣ Create a New Branch

Never work directly on `main`.

```bash
git checkout -b feature/your-feature-name
```

Examples:

```
feature/add-login-page
fix/button-alignment
docs/update-readme
```

---

## 4️⃣ Make Your Changes

You can:

* Fix bugs
* Add features
* Improve UI
* Optimize code
* Update documentation

Please follow the project’s coding style.

---

## 5️⃣ Test Your Changes

Before submitting:

✅ Make sure the project runs
✅ No errors appear
✅ Existing features still work

---

## 6️⃣ Commit Your Changes

Use clear commit messages.

```bash
git add .
git commit -m "Added calculator button layout fix"
```

Good commit message examples:

* `Fix navbar alignment`
* `Add music player feature`
* `Improve README documentation`

---

## 7️⃣ Push Your Branch

```bash
git push origin feature/your-feature-name
```

---

## 8️⃣ Create a Pull Request (PR)

1. Go to your fork on GitHub
2. Click **Compare & Pull Request**
3. Describe your changes clearly
4. Submit the Pull Request

## ❤️ Thank You
